# External reference resources

This directory is reserved for external soybean genomic reference resources used in the Flyer × Hartwig linkage-map and QTL reanalysis.

The reference files are not primary data generated by this study. They were obtained from SoyBase and correspond to the Williams 82 soybean reference genome assembly Wm82.gnm6.

## Required files

The analysis notebooks use the following resources:

### SoySSR marker reference

File expected by the notebooks:

`glyma.Wm82.gnm6.mrk.SoySSR.gff3.gz`

This file contains physical positions of SoySSR markers on the Wm82.gnm6 soybean reference genome and was used for independent physical anchoring of markers in the reconstructed Flyer × Hartwig linkage map.

### Gene-model annotation

File expected by the notebooks:

`glyma.Wm82.gnm6.ann1.PKSW.gene_models_main.gff3.gz`

This file contains gene-model annotations for the Wm82.gnm6 assembly and was used for physical localization and candidate-gene analyses.

## Source

Both resources were obtained from SoyBase:

https://www.soybase.org/

Users wishing to reproduce analyses that require these reference files should obtain the corresponding Wm82.gnm6 resources from SoyBase and place them in this directory using the filenames shown above.

## Repository structure

After obtaining the reference resources, this directory should contain:

reference/
├── README.md
├── glyma.Wm82.gnm6.mrk.SoySSR.gff3.gz
└── glyma.Wm82.gnm6.ann1.PKSW.gene_models_main.gff3.gz

The notebooks locate these resources relative to the repository root and do not require machine-specific absolute paths.

## Citation

SoyBase and the specific genome/reference resources used in this study should be cited as described in the associated manuscript and according to the citation guidance provided by SoyBase.
